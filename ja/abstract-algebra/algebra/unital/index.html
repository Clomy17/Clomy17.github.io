双単位的双代数

可換環 𝕂 を与える．

  • 双単位的双代数(biunital bialgebra)とは，以下のデータからなる：
    • 𝕂-加群 𝐴
    • 𝐴 上の 𝕂-双線型写像 ⋅ : 𝐴⊗𝐴 → 𝐴
    • 単位(unit)と呼ばれる 𝕂-線型写像 𝜂 : 𝕂→𝐴
    • 𝐴 上の 𝕂-余双線型写像 𝛥 : 𝐴 → 𝐴⊗𝐴
    • 余単位(counit)と呼ばれる 𝕂-線型写像 𝜀 : 𝐴→𝕂
    これらは以下を満たす：
    • ( 𝐴,⋅,𝜂 ) は単位的代数
    • ( 𝐴,𝛥,𝜀 ) は余単位的余代数
    • 以下の同値な条件のいずれか（ゆえに全て）：
      • ⋅,𝜂 は余単位的余代数準同型
      • 𝛥,𝜀 は単位的代数準同型
  • 双単位的双代数 ( 𝐴,𝑚,𝜂,𝛥,𝜀 ) が，
    • 結合的かつ余結合的なとき，双結合的(biassociative)と呼ぶ．
    • 可換的かつ余可換的なとき，双可換的(bicommutative)と呼ぶ．

Hopf代数

可換環 𝕂 を与える．

  • Hopf代数(Hopf algebra)とは，以下のデータからなる：
    • 双単位的双結合的双代数 ( 𝐴,𝑚,𝜂,𝛥,𝜀 )
    • 対蹠(antipode)と呼ばれる 𝕂-線型写像 𝑆 : 𝐴→𝐴
    これらは以下を満たす： 𝑚 ∘ ( id⊗𝑆 ) ∘ 𝛥 = 𝜂∘𝜀 = 𝑚 ∘ ( 𝑆⊗id ) ∘ 𝛥
  • Hopf代数 ( 𝐴,𝑚,𝜂,𝛥,𝜀,𝑆 ) が対合的(involutive)であるとは， 𝑆∘𝑆 = id を満たすことを言う．

  • 三角双代数(triangular bialgebra)とは，準三角双代数 ( 𝐴,𝑚,𝜂,𝛥,𝜀,𝑅 ) であって， 𝜎 ⁡ (𝑅) = 𝑅 −1 を満たすものを言う．

  • 可換環 𝕂
  • 準三角双代数 ( 𝐴,𝑚,𝜂,𝛥,𝜀,𝑅 )

を与えると，以下が成り立つ：

  • ( 𝜀 ⊗ id𝐴 ) ⁢ 𝑅 = 1
  • ( id𝐴 ⊗ 𝜀 ) ⁢ 𝑅 = id𝐴
  • Yang-Baxter方程式(Yang-Baxter equation)： 𝑅 1,2 ⁢ 𝑅 1,3 ⁢ 𝑅 2,3 = 𝑅 2,3 ⁢ 𝑅 1,3 ⁢ 𝑅 1,2
