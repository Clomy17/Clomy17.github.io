代数・余代数と準同型

単位的代数・余単位的余代数

可換環 𝑅 を与える．

  • 𝑅上の代数（または多元環）(algebra)とは，以下のデータからなる．
    • 𝑅-加群 𝐴
    • 𝐴 上の 𝑅-双線型写像 ⋅ : 𝐴⊗𝐴 → 𝐴
    • 単位(unit)と呼ばれる線型写像 𝜂 : 𝕂→𝐴
    これらは以下を満たす： ∀ ⁡ 𝑎∈𝐴 , 𝜂 ⁡ (1) ⁢ 𝑎 = 𝑎 = 𝑎 ⁢ 𝜂 ⁡ (1)
  • 𝑅上の余代数(coalgebra)とは，以下のデータの組のこと：
    • 𝑅-加群 𝐴
    • 𝐴 上の 𝑅-余双線型写像 𝛥 : 𝐴 → 𝐴⊗𝐴
    • 余単位(counit)と呼ばれる線型写像 𝜀 : 𝐴→𝕂
    これらは以下を満たす： ∀ ⁡ 𝑎∈𝐴 , ( id⊗𝜀 ) ⁡ ( 𝛥 ⁡ (𝑎) ) = 𝑎 = ( 𝜀⊗id ) ⁡ ( 𝛥 ⁡ (𝑎) )

準同型

可換環 𝑅 を与える．

  • 𝑅-代数 𝐴,𝐴′ に対し，
    • （𝑅-単位的代数）準同型(homomorphism)とは，写像 𝑓 : 𝐴→𝐴′ であって以下を満たすもの：
      • 𝑓 は 𝑅-線型写像
      • ∀ ⁡ 𝑥,𝑦 ∈ 𝐴 , 𝑓 ⁡ ( 𝑥⁢𝑦 ) = 𝑓 ⁡ (𝑥) ⁢ 𝑓 ⁡ (𝑦)
    • 𝐴 から 𝐴′ への自己準同型全体の集合を hom ⁡ ( 𝐴 , 𝐴′ ) と表す．
  • 𝑅-余代数 𝐴,𝐴′ に対し，
    • （𝑅-余代数）準同型(homomorphism)とは，写像 𝑓 : 𝐴→𝐴′ であって以下を満たすもの：
      • 𝑓 は 𝑅-線型写像
      • ∀ ⁡ 𝑥∈𝐴 , 𝛥 𝐴′ ⁡ ( 𝑓 ⁡ (𝑥) ) = 𝑓⊗𝑓 ⁡ ( 𝛥𝐴 ⁡ (𝑥) )
  • 全単射な準同型を同型(isomorphism)と呼ぶ．
