単位的代数・余単位的余代数

可換環 𝕂 を与える．

  • 𝕂上の単位的代数(unital algebra)とは，以下のデータからなる．
    • 𝕂-加群 𝐴
    • 𝐴 上の 𝕂-双線型写像 ⋅ : 𝐴⊗𝐴 → 𝐴
    • 単位(unit)と呼ばれる 𝕂-線型写像 𝜂 : 𝕂→𝐴
    これらは以下を満たす： ∀ ⁡ 𝑎∈𝐴 , 𝜂 ⁡ (1) ⁢ 𝑎 = 𝑎 = 𝑎 ⁢ 𝜂 ⁡ (1)
  • 𝕂上の余単位的余代数(counital coalgebra)とは，以下のデータの組のこと：
    • 𝕂-加群 𝐴
    • 𝐴 上の 𝕂-余双線型写像 𝛥 : 𝐴 → 𝐴⊗𝐴
    • 余単位(counit)と呼ばれる 𝕂-線型写像 𝜀 : 𝐴→𝕂
    これらは以下を満たす： ∀ ⁡ 𝑎∈𝐴 , ( id⊗𝜀 ) ⁡ ( 𝛥 ⁡ (𝑎) ) = 𝑎 = ( 𝜀⊗id ) ⁡ ( 𝛥 ⁡ (𝑎) )

可換環 𝕂 を与える．

  • 𝕂-単位的代数 𝐴,𝐴′ に対し，

  • 𝕂-余単位的余代数 𝐴,𝐴′ に対し，

Hopf代数

双代数とHopf代数

双単位的双代数

可換環 𝕂 を与える．

  • 双単位的双代数(biunital bialgebra)とは，以下のデータからなる：
    • 𝕂-加群 𝐴
    • 𝐴 上の 𝕂-双線型写像 ⋅ : 𝐴⊗𝐴 → 𝐴
    • 単位(unit)と呼ばれる 𝕂-線型写像 𝜂 : 𝕂→𝐴
    • 𝐴 上の 𝕂-余双線型写像 𝛥 : 𝐴 → 𝐴⊗𝐴
    • 余単位(counit)と呼ばれる 𝕂-線型写像 𝜀 : 𝐴→𝕂
    これらは以下を満たす：
    • ( 𝐴,⋅,𝜂 ) は単位的代数
    • ( 𝐴,𝛥,𝜀 ) は余単位的余代数
    • 以下の同値な条件のいずれか（ゆえに全て）：
      • ⋅,𝜂 は余単位的余代数準同型
      • 𝛥,𝜀 は単位的代数準同型
  • 双単位的双代数 ( 𝐴,𝑚,𝜂,𝛥,𝜀 ) が，
    • 結合的かつ余結合的なとき，双結合的(biassociative)と呼ぶ．
    • 可換的かつ余可換的なとき，双可換的(bicommutative)と呼ぶ．

Hopf代数

可換環 𝕂 を与える．

  • Hopf代数(Hopf algebra)とは，以下のデータからなる：
    • 双単位的双結合的双代数 ( 𝐴,𝑚,𝜂,𝛥,𝜀 )
    • 対蹠(antipode)と呼ばれる 𝕂-線型写像 𝑆 : 𝐴→𝐴
    これらは以下を満たす： 𝑚 ∘ ( id⊗𝑆 ) ∘ 𝛥 = 𝜂∘𝜀 = 𝑚 ∘ ( 𝑆⊗id ) ∘ 𝛥
  • Hopf代数 ( 𝐴,𝑚,𝜂,𝛥,𝜀,𝑆 ) が対合的(involutive)であるとは， 𝑆∘𝑆 = id を満たすことを言う．
Hopf代数の性質
  • 可換環 𝕂 を与える．
  • Hopf代数 ( 𝐴,𝑚,𝜂,𝛥,𝜀,𝑆 )

を与えると，以下が成り立つ：

  • 𝑆 は単位的代数準同型かつ，余単位的余代数準同型．
  • ( 𝐴,𝑚,𝜂,𝛥,𝜀,𝑆′ ) もHopf代数ならば， 𝑆 = 𝑆′

準三角双代数

  • 可換環 𝕂

を与える．

  • 準三角双代数(quasitriangular bialgebra)とは，以下のデータからなる：
    • 双単位的双結合的双代数 ( 𝐴,𝑚,𝜂,𝛥,𝜀 )
    • 普遍 𝑅-元(universal 𝑅-element)と呼ばれる可逆元 𝑅 ∈ 𝐴⊗𝐴
    これらは以下を満たす：
    • ∀ ⁡ 𝑎∈𝐴 , 𝜎∘𝛥 ⁡ (𝑎) = 𝑅 ⁢ 𝛥 ⁡ (𝑎) ⁢ 𝑅 −1
    • ( 𝛥 ⊗ id𝐴 ) ⁡ (𝑅) = 𝑅 1,3 ⁢ 𝑅 2,3
    • ( id𝐴 ⊗ 𝛥 ) ⁡ (𝑅) = 𝑅 1,3 ⁢ 𝑅 1,2
  • 三角双代数(triangular bialgebra)とは，準三角双代数 ( 𝐴,𝑚,𝜂,𝛥,𝜀,𝑅 ) であって， 𝜎 ⁡ (𝑅) = 𝑅 −1 を満たすものを言う．
準三角双代数の性質
  • 可換環 𝕂
  • 準三角双代数 ( 𝐴,𝑚,𝜂,𝛥,𝜀,𝑅 )

を与えると，以下が成り立つ：

  • ( 𝜀 ⊗ id𝐴 ) ⁢ 𝑅 = 1
  • ( id𝐴 ⊗ 𝜀 ) ⁢ 𝑅 = id𝐴
  • Yang-Baxter方程式(Yang-Baxter equation)： 𝑅 1,2 ⁢ 𝑅 1,3 ⁢ 𝑅 2,3 = 𝑅 2,3 ⁢ 𝑅 1,3 ⁢ 𝑅 1,2
