代数

定義

代数・余代数

可換環𝑅を与える．

  • 𝑅上の代数（または多元環）(algebra)とは，以下のデータからなる．
    • 𝑅-加群𝐴
    • 𝐴 上の 𝑅-双線型写像 ⋅ : 𝐴 → 𝐴⊗𝐴
  • 𝑅上の余代数(coalgebra)とは，以下のデータの組のこと：
    • 𝑅-加群𝐴
    • 𝐴 上の 𝑅-余双線型写像 𝛥 : 𝐴 → 𝐴⊗𝐴

準同型

  • 可換環𝑅
  • 𝑅-代数 𝐴,𝐵

を与える．

  • （𝑅-代数）準同型(homomorphism)とは，写像 𝑓 : 𝐴→𝐵 であって以下を満たすもの：
    • 𝑓 は 𝑅-線型写像
    • ∀ ⁡ 𝑥,𝑦 ∈ 𝐴 , 𝑓 ⁡ ( 𝑥⁢𝑦 ) = 𝑓 ⁡ (𝑥) ⁢ 𝑓 ⁡ (𝑦)
  • 𝐴から𝐵への自己準同型全体の集合を hom ⁡ ( 𝐴 , 𝐵 ) と表す．

同型

全単射な準同型を同型(isomorphism)と呼ぶ．

自己準同型

自己準同型・同型

  • 可換環𝑅
  • 𝑅-代数𝐴

を与える．

  • 𝐴 上の代数準同型のことを，自己準同型(endomorphism)と呼ぶ．自己準同型の集合をend⁡𝐴と書く．
  • 𝐴 上の代数同型のことを，自己同型(automorphism)と呼ぶ．自己同型の集合をaut⁡𝐴と書く．

微分代数

微分代数

  • 可換環 𝑅
  • 𝑅-代数𝐴

を与える．

𝐴上の微分とは，（𝑅-加群𝐴としての）線型変換 𝑑 : 𝐴 → 𝐴 であって以下を満たすもの：

Leibniz則
𝑑 ⁡ ( 𝑥 ⁢ 𝑦 ) = 𝑥 ⁢ 𝑑 ⁡ ( 𝑦 ) + 𝑑 ⁡ ( 𝑥 ) ⁢ 𝑦

𝐴の微分全体がなす集合をder⁡𝐴と書き，これはLie環をなす．
